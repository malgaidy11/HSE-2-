# HSE 2 — Portable Local HSE Control Center

No Node.js, no npm, no login, no server required.

## Run
Download ZIP, extract it, then double-click **HSE-Control-Center.html**. It opens in Chrome/Edge.

## Local-only data
Contractors, settings and future notes are stored in the browser on this computer. Use Settings > Export Backup.

## Excel safety
The design is read-only. It does not save, overwrite or modify source Excel files.

## Source slots prepared
- Incidents — internal network file path to be connected later.
- Potential Incidents — internal network file path to be connected later.
- PTW — SharePoint mapping to be completed later.
- Training — SharePoint mapping to be completed later.

Automatic network-file access is intentionally not enabled until exact paths and workbook structures are mapped.
